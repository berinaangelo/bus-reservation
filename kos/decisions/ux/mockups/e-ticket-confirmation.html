Save/screenshot emphasis

SMS/email notifications are cut for MVP (mvp-scope.md cut #2), so this on-screen render is the rider's only durable copy of the ticket until that ships. The primary CTA carries that weight explicitly — full width, first in the visual order, not a quiet "Done" link.

Implementation notes

  • QR-secondary, reference_code-primary is a deliberate resolution, not an oversight. mvp-scope.md and reference-code-format.md both cut QR camera-scan check-in from MVP (staff hand-type the code at the counter), while PLAN.md and god-moments.md #3 still describe the ticket as "QR + reference_code." This mockup keeps the QR (both docs name it) but makes reference_code the dominant, functional element and labels the QR "scan not required" so the UI itself teaches the correct mental model instead of leaving it ambiguous.
  • Scope boundary: this screen starts at "paid." It renders once Booking.status = confirmed and Payment.paid_at is set. Any "processing payment" transitional state gestured at in payment-idempotency.md belongs to the payment-step screen, not this one.
  • No email fallback exists yet. Per mvp-scope.md cut #2, SMS/email notifications are out for v1 — this render is the rider's only durable copy, which is why "Save Ticket" is the promoted primary action rather than a generic "Done."
  • Glyph ambiguity matters more at hero size. typography.md has an open follow-up on 2/Z, 5/S, 6/G distinguishability — worth a real confirmation pass before this ships, since the code is now rendered at text-5xl as the visual centerpiece of the screen.
  • QR is a static placeholder. No QR-generation library is wired into this static mockup — the boxed grid icon stands in for a real encoded QR and is not a decided visual treatment.
  • Option B (Reference Code Hero) chosen. Options A and C stay in the comparison above for reference, same as rejected options are kept (not deleted) elsewhere in this KOS. A laws-of-ux pass is deferred until a batch of mockups is ready for review, per this project's standing practice.
