Decided (placeholder, not final): platform wordmark is a **"TS" monogram** — short for
**Terminal Signal**, the [[color-scheme|color identity's]] own name — set in Barlow Condensed
Bold, used as-is for header logo/favicon until a proper mark is designed.

This is explicitly a stand-in, not a finished logo decision: no wordmark lockup, no icon mark, no
usage/clearspace rules yet. Scoped separately from operator logos, which are just per-operator
data ([[../tech-stack|Operator.logo]]) rendered wherever an operator is shown — this decision is
only about the platform's own identity mark (header, favicon, e-ticket branding).

**Revisit before it ships broadly** — fine for internal builds/screenshots, but a two-letter
monogram in the display face is the kind of placeholder that's easy to forget to replace.

See [[color-scheme]] and [[typography]] for the palette/type it's set in.
